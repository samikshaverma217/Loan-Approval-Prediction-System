# 🏦 Loan Approval Prediction System

## Introduction
Ye project bank loan approval ko predict karta hai. User apni details dalta hai jaise Income, Credit Score, Loan Amount, aur system batata hai ki Loan APPROVED hoga ya REJECTED.

## Features
- Applicant details form - Age, Income, Loan Amount, Credit Score, Employment
- Rule-based ML Prediction - Credit Score > 650 to Approval chance zyada
- 4 Graphs:
    1. Credit Score Gauge Chart
    2. Income vs Loan Amount Bar Chart
    3. Approval Probability Pie Chart
    4. Loan Term vs EMI Line Chart
- Automatic EMI Calculator
- Clean and Professional UI

## Technologies Used
- Python - Main programming language
- Streamlit - Website banane ke liye
- Pandas - Data handle karne ke liye
- Plotly - Graphs banane ke liye
